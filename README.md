# IdeaVault

Live Website:
https://ideavault-five.vercel.app/

## Features

- Users can register and login using email/password
- Google authentication supported
- Users can add startup ideas
- Users can edit and delete their own ideas
- Users can comment and interact with startup ideas
- Dark and Light theme available

## Technologies Used

- Next.js
- MongoDB
- Better Auth
- Express.js
- Tailwind CSS
- JWT
